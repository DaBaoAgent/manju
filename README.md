# manju — 佳康顺康复辅具 AI 漫剧生产线

把佳康顺（老年康复辅具）产品软植入 AI 漫剧，在品牌号定期更新推广。

当前进度：EP001《老周出门》五份创作文档与「即梦执行包」已完成（17 镜 / 150 秒），等待出片。

## 目录结构

| 目录 | 内容 |
|---|---|
| `adapters/` | 生产 adapter：GPT-SoVITS 配音、AutoDL H3 视频/对口型（付费闸门 `prepare → confirm → run`） |
| `scripts/` | 公司知识库抓取（`kb_files.py`）、即梦执行包汇总（`build_jimeng_pack.py`）、参考图行同步（`sync_ref_lines.py`） |
| `projects/kangfu-001/` | 正式剧集项目（9:16 竖屏，6 集 × 150 秒） |
| `assets/refs/jks/` | 佳康顺产品素材：助行器「朋友2」白底图 10 张、电商主图 5 张、实拍 19 张 + 31 份产品参数 |
| `docs/` | 交接文档、公司知识库接入说明 |
| `deploy/` | 早期 AutoDL 登录/扫码脚本（路线已弃用，仅备查） |

## 工作流

剧本 → 视觉设定 → 分镜（冻结关键帧）→ 图片提示词 → 视频提示词 → 即梦执行包 → 出片 → 配音 → 剪辑

`projects/kangfu-001/交付/EP001-即梦执行包.md` 是逐镜可操作版本：每镜的挂图清单、首帧图提示词、视频提示词与秒数。

## 生产链路

- **视频**：Seedance 2.0 方言（即梦），中文提示词，原生 4–15 秒
- **配音**：GPT-SoVITS 本地 CPU 音色克隆
- **素材**：公司知识库（文字走 MCP，原图走 HTTP 文件服务）
