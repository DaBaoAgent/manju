# 佳康顺 F3Q 代步车 · 参数与卖点

> 产品定位：**可折叠拆分的四轮代步车**（红色车身 · 座椅可翻折 · 带电量显示与调速控制面板）
> 品牌口号：孩子孝 爸妈笑 | 佳康顺 18 年专注医疗器械生产研发

## 一、核心卖点

> 说明：产品图（黑底棚拍 + 白底实拍）为纯外观展示，图中无文字化卖点文案与参数数值，以下卖点依据图片外观特征归纳，具体数值以官方资料为准。

### 1. 可折叠可拆分，收纳搬运都省心
- 产品图展示座椅向后翻折、方向立管倾斜的半拆解状态，车架多处折叠铰链与快拆卡扣，可对折收纳、便于放入汽车后备箱。

### 2. 电量显示面板，剩余电量一目了然
- 控制面板带电池图标电量显示（E–F 电量格），配电源按键、钥匙电门锁（图中插有钥匙）、速度调节旋钮与喇叭/灯光按钮，老人操作直观简单。

### 3. 四轮 + 双防倾轮，稳稳当当
- 前后四轮布局，后轮为大直径越野纹轮胎；车尾配两个黑色防倾小轮，过坎上坡不易后倾。

### 4. 立管高度可调，适应不同身高
- 方向柱带星形快拆螺母，可调节高度，不同身高的老人都能找到舒适操控姿势。

### 5. 加厚座椅 + 可翻起扶手，上下车方便
- 黑色 PU 加厚坐垫带白色滚边，配靠背与双侧可翻起扶手，老人从侧面上下车更轻松。

### 6. 大轮越野胎纹，多路况适应
- 后轮大尺寸轮胎带粗犷越野纹路，小区砖路、公园土路都能走，抓地力好。
