# 佳康顺 free go 智能轮椅 · 参数与卖点
> 产品定位：FREEGO 智能电动轮椅（自主移动机器人轮椅），白黄撞色仿生设计 + 智能感知模块，主打「科技 + 关怀」的高端智能出行款。

---

## 一、核心卖点

**智能感知模块，环境看得见**
前方中央黑色智能控制盒集成摄像头/深度传感器（可见圆形镜头），具备环境感知能力，支持避障/智能辅助等智能功能，是整车的核心科技卖点。

**大屏平板触控，交互更友好**
智能模块上方通过可调节支架连接大尺寸平板电脑/显示屏，屏幕角度可俯仰调节，触控操作直观，老人易上手。

**仿生机器人造型，未来感设计**
白色壳体 + 关节式折叠连杆结构（类似机械腿），圆润流线线条，包裹式白色护罩遮盖轮组电机，呈现仿机器人造型的未来科技感。

**白黄撞色 + 灯芯绒软包座椅，舒适有格调**
白色车架 + 芥末黄灯芯绒/罗纹针织面料坐垫与高包裹一体式靠背（桶椅造型），厚实饱满，坐感舒适、视觉高级。

**四轮独立摆臂悬挂，行驶平稳**
四轮设计（后轮大、前轮小），黑色橡胶防滑胎，轮组通过白色摆臂式悬挂结构与车架连接，行驶更平稳。

**加宽翼式扶手 + 扬声器格栅，细节讲究**
两侧翼式宽大扶手带黄色织物软包垫，右侧扶手前端带黄色格栅状部件（疑似扬声器/散热格栅），细节做工讲究。

**一体式防滑脚踏，承托舒适**
前部白色一体式脚踏平台带横向条纹防滑纹理，由弯管支架托举，双脚承托稳定。

**FREEGO 品牌标识，科技品牌背书**
控制模块正面印有白色「FREEGO」品牌字样（下方疑似品牌标语），整体呈现「科技 + 关怀」的产品定位。
