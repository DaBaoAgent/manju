# 佳康顺 KY250 电动轮椅 · 参数与卖点

> 产品定位：**胖人/大体重人群专用电动轮椅**（加宽 · 加大 · 加重）
> 品牌口号：孩子孝 爸妈笑 | 佳康顺 18 年专注医疗器械生产研发

---

## 一、核心卖点

### 1. 加大承重，专为大体型设计
- 承重 **150kg（300斤）**，偏胖人士久坐不挤压
- 容纳更大身形，出行无束缚

### 2. 座椅加宽，乘坐更舒适
- 座位宽度 **52cm**，胖人坐着不拥挤
- 对比普通轮椅 45cm 窄座，坐感更宽松稳固

### 3. 加固车架，不侧翻
- 高强度碳钢车架，**三角结构**更稳固
- 加厚碳钢合金，比普通细车架更坚固耐用

### 4. 多重减震系统，无惧颠簸
- 减震效果好，石子路、坑洼路长时间出行也舒服

### 5. 大马力增程电机，轻松爬坡过坎
- **双 350W 电机（合计 700W）**，动力强劲，主动降噪、低损耗、持久耐用
- 台阶、门槛轻松越障

### 6. 加宽加厚实心轮胎
- 前轮 8 寸 / 后轮 12 寸，耐磨防滑、轻松越障
- 公园、菜场颠簸路不怕扎胎爆胎，大体重长期使用不易鼓包变形
- 多路况适应：石子路 / 坑洼路 / 玻璃碎片路 / 减速带

### 7. 智能电磁刹车，驻停不溜车
- 松手即停，更稳定更安全
- 坡道驻停不溜车，制动与电量无关，任何时候稳稳停下

### 8. 智能语音控制器，操控简单易上手
- 功能图标一目了然，老人上手就会
- 按键：电源开关、喇叭、速度加/减档、警报系统、静音按钮、**SOS 紧急呼救**
- **控制器可双侧安装**（左/右），适应不同使用习惯

### 9. 便携折叠，收纳不占空间
- 可快速折叠，折叠小巧，轻松放入汽车后备箱
- 居家角落收纳不占地方

### 10. 满分细节，严控每个环节
| 细节 | 说明 |
|------|------|
| 反光条设计 | 白天醒目提醒路人，夜晚反光更安全 |
| 电池可拆卸 | 快速拆卸，方便老人充电 |
| 免弯腰充电 | 控制器下带充电口，一插即可 |
| 防倾倒后轮 | 防止爬坡时坡度过大后倾摔倒 |
| 脚踏可折叠 | 方便上下车，也方便收纳 |
| 陪护侧推把手 | 行驶或上下坡辅助借力，提升安全性 |
| 两侧储物筐 | 扶手外侧随手可拿，放置随身物品 |

- **适用人群**：偏胖/大体重人群（承重 300 斤）、行动不便的老人、术后康复者
- **适用场景**：公园散步、买菜购物、商场超市、医院就医、居家代步
