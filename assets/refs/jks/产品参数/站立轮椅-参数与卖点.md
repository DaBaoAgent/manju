# 佳康顺 站立轮椅 · 参数与卖点
> 产品定位：坐立两用站立式轮椅，通过连杆升降机构辅助用户从坐姿平稳过渡到站立，主打「站立康复 + 生活自理」的康复护理款。

---

## 一、核心卖点

**坐立两用，辅助站立康复**
通过坐垫下方的平行四边形连杆升降机构 + 银色气弹簧（推杆）驱动，座背总成可整体抬升，帮助用户由坐姿平稳转换为站立姿势，是站立功能的核心卖点。

**站立改善血液循环，延缓机能退化**
站立位有助于促进下肢血液循环、锻炼腰腿力量、预防久坐并发症，改善康复期用户的身体机能。

**膝部挡垫 + 胸垫固定，站立安全稳固**
座前下方配备黑色软垫膝挡块（站立时防止屈膝），靠背前方另有弧形胸垫/躯干固定板，配合加宽反光条安全绑带，站立姿态固定可靠。

**网布张力靠背 + 软包头枕，舒适透气**
大面积黑色透气网布张力靠背 + 加厚软包头枕（可拆洗设计），透气减压；坐垫带拉链结构，外套可拆洗。

**24 寸辐条大轮 + 手推圈，可自主推行**
大尺寸钢丝辐条后轮配黑色手推圈，用户可自主手摇推行；前轮万向小轮，转向灵活。

**可折叠交叉车架，运输收纳方便**
车架带折叠交叉支架结构与多处快拆锁紧件，整车可折叠，便于运输与收纳。

**可调腿托 + 防滑脚踏，适配不同身高**
腿托支架带多个高度调节孔位 + 银色快拆锁扣，脚踏板防滑设计，可按小腿长度精准调节。

**UNQ 品牌高端定位**
车架标牌印有红色「UNQ」品牌标识，全黑哑光车架配色，低调专业，定位康复医疗器材高端款。

## 三、适用人群与场景

- 下肢无力但可部分承重、需要站立康复训练的用户（如脑卒中康复期、术后康复期）
- 长期坐轮椅、希望改善血液循环与预防压疮的老年人
- 需要与他人平视交流、够取高处物品的生活场景
- 居家康复、医院康复科、养老机构等场景
