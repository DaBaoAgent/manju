# 佳康顺 P16L可上飞机款电动轮椅 · 参数与卖点
> 产品定位：铝合金超轻折叠电动轮椅（U-LITE 系列），主打「可上飞机、轻便折叠」的商务差旅出行款。

---

## 一、核心卖点

**U-LITE 超轻系列，轻量便携**
扶手管上印有「U-LITE」系列标识（意为「超轻」），整车银白铝合金管材 + 细管径设计，主打轻量化，折叠后可像行李箱一样提拎。

**紧凑折叠，收纳出行两相宜**
X 形交叉折叠连杆机构 + 顶部黑色提手/拉带，折叠后体积紧凑、可直接提拎，配合「可上飞机」定位，适合高铁、飞机等长途出行。

**银色车架 + 红色点缀，设计亮眼**
银白色铝合金车架配红色扶手支撑管，银+红+黑撞色设计，外观清爽有活力。

**透气网布坐靠 + 人体工学压线**
黑色 3D 网布坐靠带竖向分仓压线设计，形成多条纵向支撑带，兼顾透气性与支撑性，久坐不闷。

**离合切换杆，电动手动两用**
后轮电机旁配置黄色离合/自由滑行切换拨杆，断电时即可切换为手动推行模式，双保险出行。

**控制器带 USB 接口，随时充电**
摇杆控制器侧面带圆形充电插孔和 USB 接口，可为手机等随身设备应急充电。

**可拆卸电池 + 多接口配置**
座位下方黑色电池盒/电控总成带红色开关，后置轮毂电机带散热结构，电池可取下单独充电。

**防滑脚踏 + 脚背绑带，乘坐安全**
脚踏板带防滑纹路并配黑色脚背绑带（防滑脱），脚踏管带快拆/翻转结构，上下车方便。

## 三、适用人群与场景

- 经常出差、坐飞机/高铁的轻度行动不便人群
- 需要频繁折叠提拎、收纳空间有限的用户（如电梯房、小户型）
- 家属照护陪同出行、旅游度假场景
- 对整车颜值有要求、喜欢亮色点缀的年轻用户
