# 佳康顺 F4 镁合金高端代步车 · 参数与卖点

## 一、核心卖点

> 说明：产品图（黑底棚拍/白底主图/多角度实拍）为纯外观展示，图中无文字化卖点文案与参数数值，以下卖点依据图片外观特征归纳，具体数值以官方资料为准。

### 1. 镁合金车架，轻量高端
- 整车采用金属车架（产品定位为镁合金材质），金属烤漆质感光亮，结构紧凑轻巧，搬运、拎起不费力（整备重量待补充）。

### 2. 整车全折叠，收纳便携
- 产品图多角度展示折叠形态：座椅向前翻折放平、方向立管向下折叠，整车呈扁平紧凑状态，可放入汽车后备箱；折叠锁扣处标注「闭合 / 打开」操作指示，使用直观。

### 3. 蜂窝免充气实心胎 + 五辐星形轮毂
- 四轮均配蜂窝镂空结构免充气实心胎，防扎防爆免维护；五辐星形轮毂造型运动，整车档次感高。

### 4. 车尾双防倾轮，上坡不后翻
- 后部配两个黑色防倾小轮，配合四轮低重心布局，坡道、过坎更安全。

### 5. 前后双收纳包，出行随身装
- 车头挂灰色帆布收纳包（带网袋），座椅后方另有灰色大容量置物包，购物、随身物品分区收纳。

### 6. 电量显示 + 钥匙启动 + 调速旋钮，操控简单
- 控制面板带电量显示条、钥匙电门锁（图中插有钥匙）、速度调节旋钮（龟/兔速档），一拧一按就能走，老人易上手。

### 7. 多色可选，做工精致
- 产品图可见金属深蓝色与红色两款配色；座椅黑色 PU 皮面带红色滚边、配双侧扶手与靠背，乘坐舒适有档次。
